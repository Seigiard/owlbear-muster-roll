Итог

Идея закалена. Делаем уровень tab и новый интерфейс: сайдбар вместо таб-бара и вкладки над секциями.

Вторую часть идеи — схема, из которой генерируются все виды, — отклонили. Она не упрощает код.

Передача в работу: forged-idea.md рядом с журналом. Его можно отдать в bmad-spec или bmad-build.

Что решено

Формат
У каждого шаблона (набора и одиночного листа) обязательный tabs: Tab[]. Template.sections убираем. v → 3. Пресеты и снимки v2 отклоняются, конвертера нет: пользователей пока нет.
Tab
{ title?, visibility?, sections }, строгий объект. title можно не писать, только если вкладка одна. Одна вкладка рисуется без панели вкладок.
Видимость
«Только ГМ» задаётся в пресете на двух уровнях: шаблон (уже есть) и вкладка (новое). Видимость только сужает. Скрытия отдельного листа набора нет. Если все вкладки скрыты, а шаблон нет, проверки нет: это выбор автора.
Области id
Не меняются. Поля шаблона вне повторяемых секций — одна область на все вкладки. Формула может ссылаться на поле другой вкладки.
Сайдбар
Постоянный, ~8–9 rem. Длинные имена обрезаются, полное имя — в подсказке. Минимальная window.width — 480 вместо 360.
Порядок в сайдбаре
Порядок пресета. Набор — группа: заголовок, его листы (свои листы игрока первыми), «+». Одиночные листы без заголовка. После группы — разделитель. Настройки прижаты к низу.
Вкладки
Прокручиваются в одну строку. Токен открывает повторяемый блок и выбирает его вкладку. Метка выделения на блоке в невыбранной вкладке ставит точку и на вкладку.
Рамка окна
Один компонент на расширение, preview.html и превью конструктора. Сейчас рамку собирают руками в трёх местах.
Конструктор
Вкладка — узел дерева между шаблоном и секцией. Новый шаблон начинается с одной вкладки без названия. Секции перетаскиваются между вкладками. В форме вкладки два поля: название и видимость.
Термины
Tab («Вкладка»), Sidebar, Sidebar entry. Старое значение «tab листа» уходит. sheet-tabs.ts → sidebar-entries.ts. GLOSSARY.md правится в том же коммите.

Что отклонено

ВариантПочему нет
Конструктор из zod-схемы: формы и дерево генерируютсяНастоящие исключения остаются ручными. Это значения из других данных (nameField, id в формулах), правки с побочным эффектом (переименование id в формулах, set ↔ single, смена типа поля) и особые поля ввода (формула, варианты). Форма ячейки почти вся из исключений. Код проще не станет.
Section.tab?: stringВкладка — строка, а не узел. Опечатка создаёт новую вкладку.
Необязательный tabsДве формы в каждом потребителе. Причины ради совместимости больше нет.
Сайдбар прячется ниже порога шириныВторой режим навигации ради малого выигрыша.
Проверка «все вкладки скрыты»Лишнее усложнение проверок. Автор исправит сам.

Слабые места, которые остаются

Видимая кнопка броска с формулой, где есть поле со скрытой вкладки, показывает игроку его значение в результате. Это принято: скрытие работает только в интерфейсе, как и у шаблонов.
Поднятый v отклоняет все текущие пресеты, снимки комнат и бэкап-файлы. Это допустимо, пока живых пользователей нет. После первого внешнего ГМа такой шаг уже потребует конвертера.
Ширина 480 — минимум для сайдбара с листом. Узкое окно рядом с картой станет шире, чем сейчас.

На потом

  • Кнопка сворачивания сайдбара. Состояние хранится локально на клиенте.
  • Таблица описаний узлов для навигации в src/builder/document.ts.
  • Экспорт z.toJSONSchema() для автодополнения в редакторе.
